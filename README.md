# 안동 여행 도우미

1박 2일 안동 여행에서 다음 장소를 즉석에서 고르는 모바일 PWA입니다.

## 사용법

1. 휴대폰에서 배포 URL을 엽니다.
2. `밥 먹으러`, `카페 가기`, `구경 가기` 중 하나를 누릅니다.
3. 밥/카페/구경은 중분류에서 지금 원하는 느낌을 고릅니다. 예: 찜닭, 간고등어, 젤라또, 한옥 카페, 짧은 역사 코스.
4. 장소 카드에서 주소를 확인하거나 `주소 복사`를 누릅니다.
5. 다녀온 장소는 `갔다 왔어요`로 체크합니다.
6. 다시 시작하려면 오른쪽 위 `처음부터`를 누릅니다.

길 안내 앱 연동은 넣지 않았고, 주소 표시와 복사만 제공합니다.
